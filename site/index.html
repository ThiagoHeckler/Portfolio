RAG Fiscal

Assistente que responde dúvidas de ICMS-SC, NCM e CFOP citando o artigo da lei ou o código de onde tirou a resposta.

Busca avaliada em 40 perguntas conferidas à mão: o acerto entre os 5 primeiros subiu de 35% (só vetorial) para 80% (busca híbrida + reordenação).

PostgreSQL + pgvector: busca por vetor e por texto no mesmo banco, fundidas numa consulta só.

Python, LangChain, PostgreSQL + pgvector, FastAPI, fastembed (embeddings locais)

Auditor NF-e

Recebe XMLs de NF-e e aponta erros fiscais (CFOP incompatível com o destino, NCM inválido, total que não fecha) de forma assíncrona.

API em Go recebe e enfileira; worker em Python audita com regras fiscais e LangGraph, com retentativa, fila de mensagens mortas e idempotência pela chave de acesso.

PostgreSQL: a chave de acesso é única, então a mesma nota nunca é auditada duas vezes.

Go, Python, LangGraph, AWS S3 + SQS, PostgreSQL, Docker

Ver código

Girô

Mercado virtual e estoque em dois sistemas que conversam por eventos: quando a prateleira cai abaixo do mínimo, a reposição dispara sozinha.

Sem broker externo: eventos por Transactional Outbox e consumo idempotente. O LLM só classifica tags; a reposição é determinística e auditável.

PostgreSQL: um banco por sistema, e o evento é gravado na mesma transação da venda.

Java 25, Spring Boot 4, PostgreSQL, Python + FastAPI, React

Ver código

Prospecta: CRM com agentes de IA

CRM próprio da Covalia que busca empresas no Google Maps, audita o site atual e prepara a abordagem comercial com IA.

Servidor MCP expõe as regras do CRM para o Claude Code e para uma equipe CrewAI (pesquisador, analista e redator). Os agentes só leem; a gravação passa por validação no código.

SQLite local: dados reais de clientes ficam na máquina, por isso não há demo pública.

Next.js, TypeScript, Prisma, MCP, CrewAI (Python), Electron
